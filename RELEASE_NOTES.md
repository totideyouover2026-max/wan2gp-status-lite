# Status Lite 1.0.1

Status Lite 1.0.1 can be installed alongside Status Pro safely. If both are enabled, Status Pro takes precedence and Lite remains dormant for that Wan2GP session instead of installing duplicate backend observers or a competing panel.

When Lite is enabled on its own, it continues to deliver Status Pro's live stage timeline without its history system.

The panel still provides selectable stages, live timings and ETA, model/component identities, LTX post-processing detail, multi-pass/subwindow step observations, RAM/VRAM telemetry, download progress, and recovery after the window has been minimized.

Completed-run data is not retained. There is no history UI, prompt memory, run import/export, or gallery navigation from prior runs. The ephemeral task object is discarded as soon as Wan2GP reports the task complete. Only the panel's collapsed/expanded preference is stored locally.

Status Lite and Status Pro remain alternative presentations, so most users only need one. Keeping both installed is now supported; disable Pro and restart Wan2GP whenever you want Lite to become the active edition.
